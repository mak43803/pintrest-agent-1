# BADDIES BEAUTY AUTONOMOUS MARKETER SKILL

## Overview
This skill defines the autonomous pipeline for Baddies Beauty:
- Searches viral US beauty trends (Korean Glass Skin, Sol De Janeiro, Rhode, Caudalie, Dyson alternatives).
- Creates high-converting Baddies Beauty v4.0 Pinterest Pins with premium typography & blurred backgrounds.
- Uploads pins to Pinterest with SEO titles, descriptions, and optimized Alt-text.
- Syncs affiliate links to Linktree Shop Collections (`savvyshop0965-20`).
- Self-heals code errors using local Ollama (`qwen3:8b`) and resumes pending Linktree sync items instantly.

## Verification & Recovery Protocol
1. **Watchdog Audit**: Run `python baddies_watchdog.py --fix` to verify DB stats and auto-repair missing tags.
2. **Infinite 24/7 Launcher**: Execute `run_agent_forever.bat` to maintain endless continuous operation.
3. **Pending Linktree Sync**: Always complete products in `Pinterest_Published` status before starting new pin cycles.

## Visual Design Patterns & Luxury Brand Aesthetics
- **Core Archetypes**: Rotates dynamically between Templates A–E (Minimal Luxury, Product + Beauty Texture, Lifestyle Editorial, Vanity Setup, Flat Lay).
- **Luxury Color Palette**: Warm Ivory (`#FAF5EF`), Soft Beige (`#F7F0E6`), Champagne (`#F5EBE1`), Muted Rose (`#D8A49B`), Dark Charcoal (`#1A1A1A`).
- **Typography & Symbols**: High-contrast Serif headlines + Muted Rose CTA pill buttons (`View on Amazon →`). All star symbols rendered as clean unicode (`★`, `✦`).
- **Originality**: Purely inspired by Rhode, Rare Beauty, Summer Fridays, and Dior Beauty editorial campaigns without directly copying existing pins.
